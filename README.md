# Markaz Academy Website

Official website for **Markaz Academy** — Modern STEM, Coding & Academic Excellence.

## 🚀 Live Demo
This static website can be hosted directly on [GitHub Pages](https://pages.github.com/).

## 📁 Project Structure
- `index.html` - Home page
- `courses.html` - Course catalog and track offerings
- `css/` - Custom styles (`style.css`)
- `js/` - JavaScript interactivity (`main.js`)
- `assets/` - Logos, graphics, and course images

## 🛠️ Local Development
To preview the site locally, open `index.html` directly in your browser or run a lightweight local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve
```
